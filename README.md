# AS2 结构拆装实训

AS2 四足机器人的浏览器端虚拟拆装演示。给机械、机电、机器人方向的教学和展示用：不用装软件、不用连真机，打开网页就能把整机拆开看结构。

```
git clone git@github.com:UnitreeAmelia/as2-teardown.git
cd as2-teardown && python3 -m http.server 8125
# 打开 http://127.0.0.1:8125/
```

> 必须用 HTTP 服务打开，双击 `index.html` 不行 —— ES module 与 STL 加载受 `file://` 的跨域限制。

## 它是什么

17 个刚体、12 个驱动关节的完整装配模型，三种模式：

| 模式 | 用途 |
|---|---|
| **爆炸视图** | 拖动滑块，零件沿各自连杆的装配轴分离，看装配层级 |
| **拆装实训** | 按工艺顺序拆，点错零件会告诉你错在哪、该先拆什么 |
| **自由探索** | 随便点，任意零件的档案（质量、关节行程、力矩上限、拆卸要点） |

两个可叠的标注层：

- **关节标注** — 模型转 X 光，12 个转轴以橙环标出；当前关注腿的三个关节带角度标签
- **尺寸** — 轴距 423.8 / 足端轮距 331 / 髋轴离地 370 / 大腿 212.0 / 小腿 213.44 mm，工程制图画法

## 怎么打开

双击 `启动.command`，浏览器会自动打开 `http://127.0.0.1:8125`。

需要本地起服务（不能直接双击 `index.html`）：页面用 ES module + importmap 加载 Three.js，`file://` 协议下会被 CORS 拦掉。

手动起也可以：

```bash
python3 -m http.server 8125
```

**想发给别人看**：这是个纯静态站，仓库 Settings → Pages 里把 Source 选成 `main` / `/ (root)`，存盘后几十秒就能拿到公网链接。`Three.js` 与 STL 都是相对路径，托管环境下不用改任何东西。

## 数据来源

**实测（官方 MJCF）** —— `unitreerobotics/unitree_mujoco` → `unitree_robots/as2/as2.xml`

几何尺寸、刚体层级、质量、关节轴向与行程、执行器力矩上限、关节阻尼与转子惯量、足端摩擦系数、足端接触球半径。网格为官方 17 个 STL（BSD-3-Clause）。

**工程推断** —— 材料、紧固件规格、拆卸工具、工艺顺序。官方未公开这部分，页面里以「推断」标注。实训环节的正确答案是按"末端件先拆、根部件后拆"的通用维修逻辑排的，**不是宇树官方维修手册**，教学演示可以用，实际维修请以官方手册为准。

## 实现上几个值得记一笔的坑

**腿部逆运动学要计入大腿横向偏置。** 大腿相对髋有 105.4 mm 的横向偏置，并且这个偏置随髋关节一起转动。所以腿的平面过的是"转过 q1 之后的大腿根"，不是髋原点。按髋原点解会让整机站立姿态外撇 20°。

**IK 的目标横向量是"足端到髋轴"，不是"足端到机身中线"。** 髋座本身已经在 ±60 mm 处。把 165.4 mm（60 + 105.4）当成目标喂进去，偏置就被算了两遍：髋多滚 11°、足端外扩到 451 mm，而正确值是官方 MJCF 的 331 mm 轮距。

**足端接地点在球底，不是球心。** MJCF 里足端是原点处 R28 的接触球，实际网格最低点在 −26.8 mm。按球心对齐地面，整只脚会陷进去 26.8 mm。

**尺寸标注的 z=0 是机身中心面，不是地面。** MJCF 原点在机身中心，地面在 z = −370 mm。尺寸线一开始全画在了半空。

**爆炸方向要反算到各自父坐标系。** 各连杆带旋转，给所有零件同一个世界方向，腿会像扇子一样散开；反算之后才是沿同一条装配路径退出。

## 目录

```
index.html          页面骨架
css/style.css       浅色工程风样式（教室投影、打印都够用）
js/data.js          17 个零件档案 + 16 步工艺序列（数据层）
js/viewer.js        Three.js 装配树、姿态、爆炸、关节标注
js/annotate.js      SVG 标注层（关节标签、尺寸线）
js/main.js          三种模式的状态机与交互
meshes/             官方 17 个 STL（36 MB）
vendor/             three.module.js / STLLoader / OrbitControls
```

## 已知限制

- 零件档案里的工具、紧固件是按规格推断的，不是拆机实测
- 拆装顺序是通用维修逻辑，不是官方工艺文件
- 不支持手机端手势，鼠标 / 触控板操作
